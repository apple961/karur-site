## 🔧 Technical Details

### No External Dependencies
- No API calls
- No external LLM services
- No API keys needed
- Works completely offline
- Instant responses (< 1 second)

### How Responses Work
1. User sends message
2. System analyzes keywords and patterns
3. Matches to knowledge base
4. Returns detailed, contextual response
5. Simulates "thinking" delay (800-1200ms) for natural feel

### Performance
- **Response time:** Instant (800-1200ms simulated delay)
- **Accuracy:** High for covered topics
- **Coverage:** ~20+ major topics
- **Languages:** 2 (English & Tamil)
- **Bundle size:** Minimal (~30KB for chatbot)
